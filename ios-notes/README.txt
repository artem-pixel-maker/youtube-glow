IPHONE / SAFARI STATUS — V2.0

Working now:
- The responsive companion dashboard can be opened in Safari.
- If hosted over HTTPS, users may be offered Add to Home Screen for a web-app-like launch.
- Preferences stay local in Safari storage; JSON export/import is supported.

Not included in this package:
- A signed Safari Web Extension app.
- Xcode project, Apple developer signing, App Store packaging, or injection into the official YouTube iOS app.

Reason: Safari extensions on iOS are separate Apple-platform app targets and need platform-specific build/testing and signing. The companion dashboard is not a substitute for a Safari extension.
