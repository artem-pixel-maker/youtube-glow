YOUTUBE HIGHLIGHTS AND AMBIENT LIGHTS v1.2
Private local Chrome extension.

INSTALL / UPDATE
1. Extract this ZIP to a permanent folder.
2. Open chrome://extensions in Chrome.
3. Turn on Developer mode.
4. For a new install, click Load unpacked and select this folder (the one containing manifest.json).
5. For an existing install, click the Reload icon on this extension's card.
6. Refresh YouTube. If already on a video, refresh the video page once.

FEATURES
- Purple ambient glow around the player.
- Focus mode hides selected recommendations, comments, shelves, and engagement panels. It intentionally does not hide the entire #secondary sidebar or any player-control container, to avoid breaking watch-page buttons.
- Left YouTube navigation gains YOUR TOOLS buttons for Ambient lights, Focus mode, and Glow controls.
- Watch pages gain buttons directly below the player for lights, focus, seek, play/pause, and speed.
- Hides some visible ad-related UI containers; it does not guarantee all ads disappear or bypass YouTube restrictions.
- Keyboard: Alt+L lights, Alt+H focus, Alt+Left/Right seek 10 seconds, Alt+Up/Down volume, Alt+S cycle speed.
- Attempts animated color tiers for channel names when subscriber counts are visible in the page's rendered card text.
  Blue: 100M+; green: 10M–99.9M; red: 1M–9.9M; purple: 100K–999K; gray: 10K–99K; cyan: 1K–9K; silver: 100–999.
  Important: YouTube's subscriptions feed usually does not show each channel's subscriber count. This extension will not guess counts or query an external service, so names without a visible count won't be tier-colored.
- Settings saved with chrome.storage.local. No external server or analytics.

TROUBLESHOOTING
If features don't appear after updating: open chrome://extensions, click Reload on the extension card, then refresh YouTube.
If the left navigation is collapsed, expand it so custom tools can appear.
YouTube changes its page markup over time, so selectors may need adjustments.


v1.2 POSITIONING
- Drag the floating ✦ button to move it anywhere on the page.
- Open the panel and use the Move floating button arrows for precise nudges.
- Use Reset to return to the default position.
- Position is saved locally.


Version 1.3 additions:
- Custom floating taskbar at the bottom of YouTube with Lights, Focus, seek, play/pause, speed, and Settings buttons.
- Control center now has Home, Settings, and Shortcuts tabs.
- Settings include accent colors (purple, blue, pink, green, orange), compact panel, and visibility toggles for the custom taskbar, left-navigation tools, and video buttons.
- Reset extension settings button. Settings stay in local Chrome storage.

To update: open chrome://extensions, click Reload on the extension (or remove the old unpacked copy and Load unpacked from this folder), then refresh YouTube.
